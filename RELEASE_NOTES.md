# NN VLA for Android v0.3.4

Public development build for ARM64 and ARMv7 devices running Android API 26 or later.

- Join a Windows-hosted room with its room key or look for a Host on the same Wi-Fi network.
- View the room roster and run network diagnostics.
- Enable phone file sharing to preview images, download files and upload to shared folders from a room-connected device.
- Open the phone’s Files link from a browser. On devices that allow the default HTTP port, you can open the VLA IP directly.

The APK was sideloaded and tested on a physical Android phone. Verify the download against [SHA256SUMS.txt](SHA256SUMS.txt).

[Android source and build instructions](https://github.com/No-Nonsense-OfficialRepo/NN-VLA-Android/tree/v0.3.4).
