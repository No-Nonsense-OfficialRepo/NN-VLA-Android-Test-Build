# No-Nonsense Virtual LAN Adapter (NNVLA) — Android Test Builds

This repository provides development APKs for NN VLA for Android. Use the app to join a room hosted by NN VLA for Windows.

## Download

- [Download the v0.3.4 APK](https://github.com/No-Nonsense-OfficialRepo/NN-VLA-Android-Test-Build/releases/download/v0.3.4/NN-VLA-Android-v0.3.4-debug.apk)
- [View the v0.3.4 release](https://github.com/No-Nonsense-OfficialRepo/NN-VLA-Android-Test-Build/releases/tag/v0.3.4)

## About this build

- **Version** v0.3.4
- **Features** Room-key join, Wi-Fi Host discovery, room roster, diagnostics and optional phone file sharing. See the [release notes](RELEASE_NOTES.md).
- **Limitation** This debug APK supports ARM64 and ARMv7 devices running Android API 26 or later.
- **Verification** The APK was sideloaded and tested on a physical Android phone.
- **Integrity** Verify the APK against [SHA256SUMS.txt](SHA256SUMS.txt).
- **Licensing** See [LICENSE](LICENSE) in this repository and the linked source repository for third-party notices.

The Android source and build instructions are in [NN VLA for Android](https://github.com/No-Nonsense-OfficialRepo/NN-VLA-Android).
